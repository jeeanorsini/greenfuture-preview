# GreenFuture

React 18 + Vite + TypeScript + Tailwind CSS v4 + Motion v12 + Lucide React.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Cloudflare Workers Builds: build command `npm run build`, output directory `dist`.

The cinematic background video is served from an external CDN.
